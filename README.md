# Papan Kerja — Dokumen Hukum

Public hosting for Papan Kerja's Terms & Conditions, Privacy Policy and delete-account page.

Hosted via GitHub Pages → https://kenariv12-jpg.github.io/papan-kerja-legal/

## Update workflow

1. Edit `terms.md`, `privacy.md` or `hapus-akun.md` locally
2. `git commit -am "Update docs"` + `git push origin main`
3. GitHub Pages rebuilds within ~1 minute
